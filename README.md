# 🛒 E-Commerce Excel Dashboard

## 📊 Project Overview

Interactive E-Commerce Sales Dashboard created using Microsoft Excel to analyze sales, profit, orders, customers, and product performance.

## 📌 Key KPIs

- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Units Sold
- Profit Margin

## 📈 Dashboard Features

- Monthly Sales Analysis
- Category-wise Sales & Profit
- Product Performance
- Customer Analysis
- Sales & Profit Trends
- Interactive Slicers
- Pivot Tables & Charts

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers
- Data Cleaning

## 📂 Project Files

- E-Commerce Excel Dashboard
- Dataset
- Dashboard Screenshots

## 💡 Project Outcome

This dashboard helps analyze E-Commerce business performance, identify top-performing products and categories, and understand sales and profit trends.
